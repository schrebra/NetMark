System Architecture

Engineered for the Enterprise

NetMark operates at the shell level. It doesn't just draw a box on the screen; it communicates with the Windows API to reserve physical desktop real estate.

🖥

SHAppBarMessage Hook

Registers directly with the OS as an Application Desktop Toolbar. Maximized windows mathematically cannot overlap the banner. Full Multi-Monitor PerMonitorV2 DPI awareness built-in.

💾

Zero Runtime Dependency

Compiled as a standalone, single-file executable embedding its own .NET 8 runtime. Drop the ~70MB payload onto any Windows 10/11 machine. No installers, no prerequisites.

⚡

Dynamic Telemetry

Built-in variables parse system state in real-time. Sub-second hooks into NetworkAddressChanged instantly update the %IP_ADDRESS% text if an adapter drops or switches.

🌐

RDP State Awareness

Listens to WTS Session change notifications. Automatically hides the banner locally when an active RDP session takes full screen, ensuring layered remote markings don't clash.

Deployment

Frictionless Rollout

Control everything from a single human-readable .ini file. Perfect for mass deployment via Microsoft Intune, SCCM, or Group Policy.

Automated Provisioning

Push the binary to your endpoints and establish persistence via registry. The configuration hot-reloads via FileSystemWatcher—modify the INI file over the network and the banner updates instantly without a process restart.

Deploy-NetMark.ps1
# Define deployment paths $targetDir = "C:\Program Files\NetMark" $exePath = "$targetDir\NetMark.exe" # Create directory and copy payload New-Item -Path $targetDir -ItemType Directory -Force Copy-Item -Path ".\NetMark.exe" -Destination $exePath Copy-Item -Path ".\NetMark.ini" -Destination $targetDir # Establish Auto-Start via Registry Set-ItemProperty -Path "HKLM:\SOFTWARE\Microsoft\Windows\CurrentVersion\Run" ` -Name "NetMark" -Value "`"$exePath`"" # Start the process for the current user session Start-Process -FilePath $exePath

Configuration Syntax

The INI file is the single source of truth. Colors support hex codes or ARGB integers. Variables like %COMPUTERNAME% and %USERNAME% are natively resolved.

Knowledge Base

System Administrator FAQ

No. NetMark runs under standard user context (asInvoker). The Windows AppBar registration API permits standard processes to reserve screen space on their own session. No UAC prompt will occur.
The UI utilizes the WS_EX_TRANSPARENT extended window style. This instructs the OS compositor to pass all mouse and hit-test events directly to the window underneath it. The banner will never accidentally steal focus.
The banner and reserved screen space disappear immediately, returning the desktop to normal. For high-security environments requiring constant up-time, we recommend deploying NetMark via a Scheduled Task with a 1-minute "restart if not running" trigger.
