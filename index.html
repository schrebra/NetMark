Features

Built for native Windows integration

💻

AppBar Integration

Registers as a native Windows AppBar. Maximized windows automatically avoid the banner — no content is ever hidden behind it.

🖥

Multi-Monitor Support

Automatically detects all connected monitors and handles monitor hot-plug, resolution changes, and mixed-DPI scaling setups.

🟠

Screen Edge Borders

Optional colored borders wrap the left, right, and bottom of every monitor (just like the live preview running on this page).

Deployment

Zero dependencies. Instant deploy.

📦 Group Policy / Intune

Push the single 70MB executable and use this registry key for auto-start.

HKLM\SOFTWARE\Microsoft\Windows\CurrentVersion\Run NetMark = "C:\Program Files\NetMark\NetMark.exe"

📁 Hot-Reloading Configuration

Edit NetMark.ini and the UI updates instantly without restarting the process.

[Settings] TextCenter=TOP SECRET // SCI BgColor=#ff8c00 FgColor=#000000 BorderEnabled=True BorderSize=4
