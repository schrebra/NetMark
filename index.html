Features

Everything you need for compliant desktop markings

NetMark is built for environments that require visible classification labels on every workstation. It integrates natively with the Windows shell for reliable, always-on-top banner display.

💻

AppBar Integration

Registers as a native Windows AppBar, reserving screen space at the top of every monitor. Maximized windows automatically avoid the banner — no content is ever hidden behind it.

🖥

Multi-Monitor Support

Automatically detects all connected monitors and places a banner on each one. Handles monitor hot-plug, resolution changes, and DPI scaling across mixed-DPI setups.

🟠

Screen Edge Borders

Optional colored borders wrap the left, right, and bottom of every monitor. The bottom border positions itself above the taskbar automatically. Same color as the banner.

🌐

RDP Session Detection

Automatically hides when a full-screen RDP client is detected on either end of the session. Banners reappear instantly when returning to the local console. No manual toggling required.

📁

Single-File Portable EXE

Ships as one self-contained executable with no .NET runtime requirement, no installer, and no dependencies. Drop it on a machine and run. Approximately 70 MB with everything embedded.

📊

Live Configuration

Edit settings via the built-in HTML configurator and save directly to NetMark.ini. The running banner picks up changes instantly — no restart needed. Includes 28+ preset classification levels.

🔁

Dynamic Variables

Built-in variables like %IP_ADDRESS% refresh automatically within 2 seconds of any network change. Also supports %COMPUTERNAME%, %USERNAME%, and custom variables.

🎨

Full Customization

Choose from 28+ USA classification presets or configure everything manually: colors, fonts, sizes, margins, drop shadows, text shadows, and border thickness. Per-monitor DPI-aware rendering.

🛡

Click-Through & Non-Interfering

The banner and borders are click-through (HTTRANSPARENT), meaning mouse clicks pass through to whatever is behind them. The banner never steals focus or interferes with application interaction.

How It Works

Three steps from download to compliant

No installer, no registry entries, no prerequisites. Just download, configure, and run.

Copy NetMark.exe to any folder on the target machine. The first launch auto-extracts the default INI and opens the HTML configurator in your browser.

Deployment

Deploy in minutes, not hours

NetMark is designed to be deployed by system administrators through any standard software distribution method.

📦 Manual Deployment

  1. Copy NetMark.exe to a folder (e.g. C:\Program Files\NetMark\)
  2. Launch NetMark.exe once to auto-generate the default NetMark.ini and open the configurator
  3. Customize settings and save NetMark.ini to the same folder
  4. Add a registry Run key for auto-start:
    HKLM\SOFTWARE\Microsoft\Windows\CurrentVersion\Run NetMark = "C:\Program Files\NetMark\NetMark.exe"

📋 Enterprise Deployment

  • SCCM / MECM: Package the EXE + pre-configured INI as an application. Deploy to device collections. Use a detection rule checking for the running process.
  • Intune: Package as a Win32 app with the EXE and INI. Use NetMark.exe as the install command (it self-extracts). Add a registry Run key via PowerShell wrapper for auto-start.
  • GPO: Place the EXE + INI on a network share. Use Group Policy Preferences to copy files locally. Use a GPO Run key for auto-start.
  • Pre-staged INI: Ship a pre-configured NetMark.ini alongside the EXE so end users never see the configurator.

📁 Configuration File Reference

The NetMark.ini file is the single source of truth for all settings. It is human-readable and can be version-controlled or templated for mass deployment.

[Settings] TextLeft=%IP_ADDRESS% TextCenter=%COMPUTERNAME% TextRight=%USERNAME% BgColor=-16745933 FgColor=-1 FontName=Segoe UI FontSize=10 FontBold=True FontItalic=False FontUnderline=False Height=24 TextShadow=False TextShadowColor=-12566464 TextShadowOffset=2 BannerShadow=False BorderEnabled=True BorderSize=0 MarginLeft=25 MarginRight=25 ; Built-in variables: %COMPUTERNAME%, %USERNAME%, %USERDOMAIN%, %IP_ADDRESS% ; Add custom static variables in an [EnvVars] section: ; MY_VAR=Some Value ; Then reference them as %MY_VAR% in the banner text above.

NetMark monitors both sides of an RDP session. On the server side (the machine being remoted into), it detects the remote session via GetSystemMetrics(SM_REMOTESESSION) and WTS session change notifications, hiding the banner when a remote session is active and restoring it when returning to the console. On the client side (the machine running mstsc), it detects full-screen RDP windows and hides the banner so the remote desktop's own banner (if any) is visible instead.
